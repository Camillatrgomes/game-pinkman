## 📖 Sobre o Projeto

Este projeto foi desenvolvido utilizando **Unity** e **C#** com o objetivo de aprender e praticar os fundamentos do desenvolvimento de jogos. Durante a construção do projeto, foram aplicados conceitos essenciais de programação, criação de mecânicas de gameplay, interface gráfica e gerenciamento de cenas.

O jogo possui uma fase jogável, onde o jogador deve coletar frutas espalhadas pelo cenário para acumular pontos e alcançar o objetivo proposto.

Durante o desenvolvimento deste projeto foram explorados conceitos como:

* Programação orientada a objetos com C#.
* Manipulação de GameObjects.
* Sistema de colisões.
* Controle de personagem.
* Interface gráfica (UI) com Canvas.
* Reprodução de áudio e efeitos sonoros.
* Gerenciamento de cenas.
* Organização de scripts e assets.
